Featured Project

Digital Dustbin

A smart, sensor-driven bin that senses and monitors waste.

Working Prototype Arduino · Ultrasonic Sensor

The Problem

In most homes and public spaces, waste ends up in the dustbin and fills up — making things harder and cities dirtier. Bins also overflow before anyone notices, leading to wasted collection trips and unhygienic surroundings.

The Idea

A "digital" bin that uses a sensor to sense an object and automatically drops it into the side. An ultrasonic sensor measures the fill level and sends an alert when the bin needs to be emptied.

Sense Waste at Source

Senses waste at the source using sensor-based detection — no manual sorting needed.

IoT Monitoring

Tracks fill level in real time so collection happens only when the bin is actually full.

Smarter Cities

A small step toward cleaner streets, fewer overflowing bins, and more efficient waste pickup.

Built With

Arduino Ultrasonic Sensor Servo Motor
